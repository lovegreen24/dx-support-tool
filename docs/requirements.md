## 1. プロジェクト概要

### 目的

税理士事務所紹介の中小企業(月1〜3社、業種問わず)に対し、訪問メモ入力と決算書等のPDF/画像データ解析を組み合わせて業務・財務・課題を把握し、クライアント別カルテと業種別ノウハウを踏まえた優先順位付き改善提案書(補助金情報・概算コスト・ロードマップ付き)を効率的に作成・フォローアップする、コンサルタント本人専用の伴走支援ツールを構築する。

### 成功指標

**定量的指標**
1. 1社あたりのヒアリング〜提案書作成にかかる時間を現状比で短縮
2. 提案書に盛り込んだ改善策・補助金情報の採用率を一定水準以上に
3. ヒアリング未回答項目・フォローアップ漏れを実質ゼロに
4. 税理士事務所からの紹介継続率・紹介数の増加

**定性的指標**
1. クライアント別カルテと業種別ノウハウの両方を活かし、毎回ゼロから資料を作らず質の高い提案ができる
2. 税理士事務所というパートナーから見て「安心して紹介できる」品質を保てる
3. 業種が違っても「うちの実情に合っている」と経営者に感じてもらえる
4. コンサルタント自身が事務作業から解放され、対話・信頼構築に集中できる

## 2. システム全体像

- 利用者: コンサルタント本人のみ(マイ専用)
- ロール: 単一ロール(フルアクセス)。将来的な事務所メンバー共有は現時点では想定しない
- 認証: 進捗ダッシュボードは簡易パスワード保護

### 推定業務フロー

1. 紹介受付(税理士事務所から企業紹介)
2. 初回ヒアリング(訪問メモ入力 + 決算書等PDF/画像アップロード)
3. データ登録・解析(クライアント登録、決算書解析、ヒアリング回答登録)
4. ヒアリング漏れチェック(未回答項目の検出・追加ヒアリング)
5. 分析(運転資金・銀行残高リスク診断、固定費ベンチマーク比較、DX成熟度診断、補助金マッチング)
6. 提案書生成(改善策一覧・優先順位・補助金情報・概算コスト・実行ロードマップ)
7. 提案・実行支援
8. フォローアップ(案件管理MCPで進捗・承認履歴を記録)

### 処理依存関係

```
save_client_record ─┬→ parse_financial_statement ─┬→ analyze_working_capital ──┐
                     │                              └→ compare_cost_benchmark ──┤
                     ├→ register_hearing_answer → remind_missing_hearing_items  ├→ generate_proposal_draft
                     ├→ assess_digital_maturity ──────────────────────────────┤
                     └→ 補助金マッチング ─────────────────────────────────────┘
```

⚠️ `generate_proposal_draft`はヒアリング全問完了が前提。`analyze_working_capital`は在庫・売掛金・買掛金等10項目の詳細数値を要求するため、`parse_financial_statement`の解析結果だけで自動的に埋まるかは実装時に確認する。

## 5. セキュリティ要件

- HTTPS強制(Cloudflare Pages標準対応)
- 入力値サニタイゼーション
- 進捗ダッシュボードは簡易パスワード保護(マイ専用のためシンプルな認証で十分)
- クライアントの財務データ・経営課題情報は機密情報として扱い、外部漏洩を防止する
- ヘルスチェックエンドポイント: `/api/health`(新規MCP・ダッシュボードのバックエンドに実装)
- グレースフルシャットダウン: SIGTERM対応、8秒タイムアウト(新規MCPサーバー)

## 8. AI設計

- **型**: エージェント型(Claude Tool Use + 自律ループ)
- **必要ツール**: 既存8MCP(財務診断系) + 新規2MCP(補助金マッチング、DX成熟度診断) + 既存2MCP(OCR・案件管理) + 新規1MCP(役員報酬最適化シミュレーション・コンサルタント本人専用)
- **自律ループ仕様**: Claude Sonnet + Tool Use、目安最大10回反復(ヒアリング項目数により前後)
- **目標自律度Lv**: L2(AIは財務分析〜提案書ドラフト生成までを自動化。経営者への提示・最終判断はコンサルタント本人が行う)
- **実行ランタイム**: 操作者=ClaudeCodeのため、自律ループはClaude Code自身が回す。MCPはツール提供のみでAnthropic APIを叩かないため、ANTHROPIC_API_KEYは不要
- **教師データ/ノウハウの所在**: 財務系MCP内のクラウドDB(クライアント別カルテ)+ 業種別ベンチマークデータ(`compare_cost_benchmark`内蔵)+ DX成熟度診断チェックリスト(福岡県商工会DXガイドの観点をベースに新規構築)

実際のシステムプロンプト本体の構築は、Phase 7(エージェント構築)で行う。
